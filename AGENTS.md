# Working on this branch

The existing Python pipeline is in the repository root. The new React UI is in `frontend/`.

Before changing frontend behavior or connecting backend responses, read `frontend/AGENTS.md` and `frontend/BACKEND_INTEGRATION.md`.

The frontend intentionally uses mock model/research responses. Preserve visible mock labels until an actual backend transport is integrated and verified. No credentials, local environments, generated builds, or patient data belong in Git.
